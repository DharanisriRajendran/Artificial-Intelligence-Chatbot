# Artificial Intelligence Chatbot – Java

## 📌 Project Overview

The Artificial Intelligence Chatbot is a simple Java-based application designed to interact with users through text-based communication.

It accepts user questions and provides automatic responses using keyword matching and rule-based Natural Language Processing (NLP) techniques.

## 🎯 Objectives

- To develop an interactive Java chatbot.
- To understand basic NLP concepts.
- To provide automatic responses to user questions.
- To improve user interaction through a console-based interface.

## ✨ Features

- Interactive chatbot communication.
- Automatic responses to user messages.
- Keyword-based question recognition.
- Predefined answers for frequently asked questions.
- Handles greetings and general queries.
- Exit option using the "bye" command.

## 🛠️ Technologies Used

- Programming Language: Java
- Concepts: String Handling, Loops, Conditional Statements
- NLP Technique: Keyword Matching
- IDE: Visual Studio Code
- JDK: Java Development Kit

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the Java program:

```bash
javac AIChatbot.java
```

5. Execute the program:

```bash
java AIChatbot
```

## 🧠 Working Principle

1. The chatbot receives input from the user.
2. It converts the input into lowercase.
3. It identifies keywords in the message.
4. It matches the keywords with predefined conditions.
5. It generates an appropriate response.
6. The interaction continues until the user enters "bye".
